# Gift Proposal Skill (企業禮贈品提案顧問)

## 🎯 Skill 目標
透過與使用者的對話引導，協助業務或行銷人員將客戶模糊、發散的禮贈品需求進行收斂，並產出結構化、可執行的標準化提案相關文件，大幅降低溝通成本並提升成交率。

## 🕒 什麼時候使用
當您收到客戶的初步詢問（例如：「我們年底需要辦抽獎，幫我想幾款實用又有質感的禮物」或「股東會紀念品需要提案」），且資訊尚不完整時，即可啟用本 Skill 協助需求訪談與文件生成。適用於：
- B2B 企業採購與大宗禮品訂製
- 品牌行銷活動、通路活動贈品（GWP/PWP）
- VIP 客戶關係經營（CRM）、年節三節禮盒

## 🔄 對話流程
1. **需求聆聽與分析**：使用者提供客戶初步的模糊需求或對話截圖。
2. **缺漏資訊盤點**：分析現有資訊，並產生「客戶待確認問題清單」，引導業務進行追問。
3. **提案發想與建議**：在資訊達標後，提供 3-5 個具體且符合預算的「禮贈品方向建議」。
4. **標準文件產出**：依據最終確認的需求，依指示產出 Proposal Brief、需求規格書或供應商詢價 Brief。

## ❓ 需求收斂問題與追問策略
**【追問策略】**
切勿一次丟出超過 3 個問題，應採用「選擇題」或「情境假設」代替開放式問答，以降低客戶回覆門檻（例如：「請問預算大概落在 $300-$500，還是 $500-$1000？」）。

**【必填資訊 (Mandatory)】**
- **送禮目的/場景**：尾牙抽獎、股東會、VIP 答謝、展場發放等。
- **目標受眾 (TA)**：年齡層、性別比例、職業屬性或生活型態。
- **預估數量**：採購總量（MOQ 評估關鍵）。
- **單價預算**：每份禮贈品的目標單價區間。
- **期望交期**：希望收到大貨的日期。

**【選填資訊 (Optional)】**
- **客製化需求**：是否需印製 Logo（雷雕/網印）、包裝腰封或客製小卡。
- **偏好材質/風格**：科技感、文青風、環保 ESG、實用辦公物等。
- **避雷清單**：客戶明言不要的品項（例如：不要馬克杯、不要行動電源）。

## 📄 支援輸出格式
請根據使用者的需求，隨時調用以下 reference 範本進行輸出：
1. **客戶需求訪談整理**：將碎片化對話整理成條列式摘要。
2. **禮贈品 Proposal Brief**：對內與對外的提案企劃大綱 (參見 `references/proposal_brief_template.md`)。
3. **禮贈品需求規格書**：給採購與設計單位的詳細規格 (參見 `references/requirement_spec_template.md`)。
4. **供應商詢價 Brief**：對外向廠商詢價的標準格式 (參見 `references/vendor_inquiry_template.md`)。
5. **客戶待確認問題清單**：協助業務追問的短訊或 Email 草稿。
6. **禮贈品方向建議**：腦力激盪後的具體品項與推薦理由。

## ⚠️ 風險提醒
- **交期與客製化**：強烈提醒客製化（如開模、特製包裝）通常需要 30-45 天以上的交期。若客戶交期低於 14 天，應主動過濾掉高客製化選項，改推現貨貼紙或公版包裝。
- **專利與版權**：避免推薦盜版或具侵權疑慮的 IP 聯名周邊。
- **稅務與運費**：在估算預算時，需提醒業務確認預算是否「含稅」、「含運（單點或多點配送）」。

## 💬 範例互動
**User:** 
客戶說下個月他們要辦 VIP 感恩餐會，大約 200 人，多半是 40 歲以上的企業高管。預算大概一人 1500 元內，要體面一點的。幫我整理一下我們還缺什麼資訊，並推薦幾個方向？

**Assistant:**
好的！這是一個針對高階 VIP 的 CRM 贈禮需求。
【目前已掌握資訊】
- 目的：VIP 感恩餐會伴手禮
- TA：40歲以上企業高管
- 數量：200 份
- 預算：$1500/份
- 交期：約下個月（偏趕）

【客戶待確認問題清單】
1. **客製化程度**：因交期僅剩約一個月，請問只需在包裝外盒加上客製腰封/小卡，還是禮品本體也必須有 Logo 烙印？（後者交期較為緊迫）
2. **體積與重量**：既然是餐會後帶走，是否需考量禮盒的重量與體積，避免賓客提拿不便？
3. **風格偏好**：過去是否有送過什麼備受好評的品項？或是否有特別想避開的種類（如酒類、食品）？

【禮贈品方向建議】
1. **方案A：品味質感生活（知名品牌茶具/手沖咖啡組）**
   - *推薦理由*：符合高管的生活品味，品牌加持能提升「體面感」。
2. **方案B：實用高階辦公（真皮客製化識別證套或筆記本組）**
   - *推薦理由*：商務人士每天必備，真皮材質具備極高質感與耐久性。
3. **方案C：紓壓與健康（高端香氛蠟燭或眼部按摩儀）**
   - *推薦理由*：展現企業對 VIP 身心健康的關懷，溫度感十足。

請問您希望我先針對哪個方向深入撰寫 `Proposal Brief` 呢？
